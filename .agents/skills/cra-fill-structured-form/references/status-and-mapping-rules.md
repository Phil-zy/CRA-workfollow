# 状态与映射规则

每个配置字段必须恰好产生一种状态：

- **已填写**：目标为空，事实已确认且唯一，写入成功。
- **已核对**：目标已有值且与确认事实一致，保留原值。
- **缺失**：没有事实、事实值为空或值为“未勾选”，保持空白。
- **冲突**：目标已有值与确认事实不一致，保留原值。
- **待确认**：事实未确认、映射不唯一、选项模糊、符号无法安全替换或字段结构不支持。
- **人工保留**：签名、签名日期、伦理委员会或其他机构专用区域，永不自动填写。

## 缺失与待确认项

如果已检查获准使用的方案、规范化信息表和项目知识库，仍找不到明确事实，字段可以保持空白。核对清单必须保留 `missing` 或 `pending` 状态，并注明由 CRA 人工确认或填写；Agent 不继续推断或补填。只要状态和处理建议已完整记录，就不阻断其他字段处理或原型验收。

## 直接字段

只对文本、日期、编号和数量执行精确事实键映射。目标为空时填写；有值时先比较规范化文本。不要覆盖公式、控件或不受支持对象。

## 选项字段

只有事实已确认且配置中的精确映射唯一命中一个选项时才勾选。不要把未勾选推断为“否”，也不要把“医疗器械临床试验”推断为“医疗器械注册临床试验”。

字符复选框只替换目标选项前的配置符号。当前样本使用 `口` 表示未选、`☒` 表示选中。允许符号与选项文字分布在多个 run 中，但必须在完整段落文本中唯一匹配，并且只替换承载目标符号的字符，保留其他 run 及其格式；无法唯一定位时标记“待确认”。

## 已有内容

- 一致：已核对。
- 不一致：冲突，不覆盖。
- CRA 对冲突作出决定后，必须生成新的待核对副本，不修改此前输出。
