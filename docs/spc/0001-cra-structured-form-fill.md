# CRA 通用结构化表单填写 Skill

状态：需求已确认，待原型开发  
更新时间：2026-07-23

## 1. 目标

为一线 CRA 提供可复用的结构化表单填写能力。Skill 从规范化项目信息文件或外部知识库读取统一项目事实，识别目标表单及模板配置，并在保留原有结构和格式的前提下填写一个 `.xlsx` 或 `.docx` 文件。

## 2. 首版范围

- 支持多种结构化表单类型。
- 每次只填写一个目标文件，不支持批量填写。
- 目标文件格式为 `.xlsx` 和 `.docx`。
- 不要求开发前收集全部未来模板。
- 新模板通过模板配置适配；出现新格式能力时才扩展 Skill 核心。
- 信函与沟通文件、监查报告附件、监查报告初稿不属于本 Skill 首版。

## 3. 输入

### 3.1 目标文件

- 一个 `.xlsx` 或 `.docx` 空白或待填写表单。
- 原文件只读，不被覆盖。

### 3.2 项目事实

按以下顺序选择一种来源：

1. 外部知识库通过知识库契约提供的已确认事实。
2. 项目工作区中的规范化项目信息文件。

多格式资料解析、OCR、邮件处理、事实归一化和版本治理由独立知识库项目负责，不属于本 Skill。

## 4. 核心概念

- **表单类型**：表单的业务用途，例如伦理修正案申请表。
- **模板配置**：某个中心或版本的具体表单版式及字段映射。
- **填写任务**：本次对一个具体目标文件执行的填写过程。

这些概念是 Skill 内部模型，不要求 CRA 在每次提示词中完整提供。

## 5. 核心流程

1. 校验目标文件、项目事实来源及工作区权限。
2. 识别目标格式、表单类型和模板配置。
3. 若模板首次出现，生成模板配置草稿并请求 CRA 确认。
4. 读取已确认的统一项目事实。
5. 执行直接字段映射和选项字段映射。
6. 对缺失、冲突、低置信度及无法唯一匹配的字段停止自动填写。
7. 将可确认内容写入新文件，不覆盖原文件。
8. 输出填写结果、缺失项、冲突项和来源记录。
9. 由 CRA 审核后决定是否正式使用。

## 6. 已确认填写规则

### 6.1 直接字段

来源事实明确且唯一时，可以自动填写文本、日期、编号和数量等字段。

### 6.2 选项字段

只有同时满足以下条件时才自动勾选：

- 来源事实状态为已确认。
- 事实能够唯一匹配模板中的一个选项。

无法唯一匹配时：

- 保持目标选项为空。
- 不推断“未勾选”等于“否”。
- 将该字段写入问题清单。

### 6.3 已有内容

- 目标字段为空时，可以正常自动填写。
- 已有值与统一项目事实一致时，保留原值并记录为已核对。
- 已有值与统一项目事实不一致时，不自动覆盖，并写入冲突清单。
- CRA 明确确认后，只能在输出副本中替换冲突值。

### 6.4 复选项写入与格式保留

- 模板包含原生复选框控件时，优先修改控件的选中状态，不将其替换为普通文本。
- 模板仅使用字符表示复选框时，由模板配置明确选中符号。
- 当前样本中，选中项的“口”替换为“☒”，未选项保持原样。
- 写入时保留原有字号、间距和布局。
- 若选中符号无法在原格式中正常显示，停止填写该字段并写入问题清单，不擅自更换字体。

### 6.5 人工保留区域

以下区域永不自动填写：

- 主要研究者签名及签名日期。
- 科室主任签名及签名日期。
- 伦理委员会或其他机构专用填写区域。

### 6.6 填写核对清单

- 每次运行除生成填写后的表格副本外，始终生成一个独立的 `.xlsx` 填写核对清单。
- 不在正式表格中添加批注、问题标记或其他审核痕迹。
- 清单中每个目标字段占一行。
- 清单至少包括：字段名称、目标位置、处理状态、来源值、目标原有值、未填写或冲突原因、来源文件及位置、建议 CRA 操作、CRA 最终决定。
- 处理状态至少包括：已填写、已核对、缺失、冲突、待确认、人工保留。
- “CRA 最终决定”由 Skill 预留为空，供 CRA 审核记录。
- `.xlsx` 和 `.docx` 目标表格共用同一种核对清单结构。

### 6.7 输出目录与命名

- CRA 可以明确指定输出目录。
- 未指定输出目录时，在目标文件所在工作区的 `output/日期时间/` 下创建本次任务目录。
- 填写结果命名为 `原文件名_待核对_YYYYMMDD-HHMMSS.原扩展名`。
- 核对清单命名为 `原文件名_填写核对清单_YYYYMMDD-HHMMSS.xlsx`。
- 同名时追加序号，任何情况下均不得覆盖已有文件。
- CRA 完成人工审核前，所有自动生成的表格均保持“待核对”状态。

### 6.8 模板配置管理

- 模板配置保存在 CRA 本地的独立模板配置库中，与 Skill 核心程序、项目知识库和具体项目文件分开管理。
- 模板配置状态分为：草稿、已启用、已停用。
- 新模板首次出现时只生成草稿配置，经 CRA 确认后才能启用。
- 只有已启用且与目标模板版本完全匹配的配置才能用于自动填写。
- Skill 通过模板结构特征识别模板版本；结构发生变化时，不继续套用旧配置，而是生成新版本草稿。
- 已启用配置不得直接改写；任何修改均创建新版本。
- 旧版本可以停用但不得删除，以保证历史任务可追溯。
- 本地模板配置库应支持独立备份、迁移及随 Skill 分发。

### 6.9 首版文档结构边界

`.docx` 首版支持：

- 普通段落。
- 表格单元格及合并单元格。
- 字符复选框和原生复选框控件。

`.xlsx` 首版支持：

- 普通单元格、合并单元格和多个工作表。
- 保留公式、样式、打印设置及工作表名称。
- 不覆盖公式。

首版暂不填写：

- 文本框、形状、图片、图表、页眉页脚、嵌入对象及动态重复区域。
- 加密、密码保护、宏或外部数据连接文件。

失败处理：

- 单个字段的结构不受支持时，跳过该字段、写入填写核对清单，并继续处理其他可安全填写的字段。
- 文件无法安全读取、复制或保存时，终止整个任务，不生成可能损坏的结果文件。

### 6.10 人工确认交互

1. 每次运行前，Skill 展示将读取的目标文件、项目信息来源、输出目录，以及是否联网或调用外部服务。
2. CRA 确认目录已获授权，且不含受试者源数据和直接识别信息后，Skill 才能继续。
3. 已启用模板配置与目标文件完全匹配时，可以直接生成待核对草稿，无需逐字段询问。
4. 新模板、模板结构变化或配置匹配不确定时，先生成字段映射草稿，必须经 CRA 确认后才能填写。
5. 缺失、冲突或无法唯一匹配的字段不阻断其他字段填写，统一留空或保留原值，并进入填写核对清单。
6. CRA 对问题项作出具体决定后，Skill 生成新的待核对副本，不修改此前输出。
7. Skill 记录 CRA 的确认结果，但不代替最终签名、发送、提交或正式归档。

### 6.11 通用约束

本 Skill 必须继承项目根目录 `PRODUCT_RULES.md` 的全部通用产品约束。

## 7. 首个样本分析

### 7.1 信息源

`fixtures/form-fill-pilot/source/project-info.xlsx`

- 一个工作表。
- 采用字段—内容结构。
- 共 18 个项目字段。
- 项目受理号为空。

### 7.2 目标模板

`fixtures/form-fill-pilot/template/XX医院 伦理审查申请表.docx`

- 主要内容为一个 20 行、6 列且包含合并单元格的表格。
- 没有 Word 内容控件或真正的复选框。
- 选项通过字符表示，需要模板配置定位并替换。

### 7.3 初步字段分类

- 可直接映射：申请日期、方案号、方案版本号、方案名称、主要研究者、研究科室、外单位协作研究者、申办者、第三方服务公司、入组人数、中心数、研究期限。
- 需要选项映射：经费来源、其他伦理委员会拒绝情况、生物样本或人遗数据外送、特定人群采集、研究类型。
- 当前缺失：项目受理号、研究结果报告和发表方式。
- 人工保留：签名、签名日期、伦理委员会填写区域。

### 7.4 已发现的数据问题

- 方案版本号必须按文本处理，避免 `1.0` 显示为 `1`。
- “未勾选”属于缺失状态，不能自动映射为“否”。
- “医疗器械临床试验”不能未经确认映射为“医疗器械注册临床试验”。

## 8. 验收标准

### 8.1 原型跑通

- 当前 Word 伦理审查申请表能够生成待核对副本和填写核对清单。
- 唯一、明确的字段全部正确填写。
- 缺失、冲突和模糊字段不被推断填写。
- 签名及机构专用区域保持不变。
- 输入文件完全不变，输出文件可以正常打开。

### 8.2 首版正式验收

- 当前 `.docx` 模板和另一个结构不同的 `.xlsx` 目标模板均通过测试。
- 第二个模板仅通过新增模板配置完成适配，不修改 Skill 核心逻辑。
- 验收样本中应自动填写的字段准确率为 100%。
- 不应自动填写的字段误填率为 0。
- 原有格式、合并单元格、公式及打印设置均按已确认边界保留。
- 每个目标字段都能在填写核对清单中找到处理状态和来源记录。
- 重复运行结果一致，且不覆盖任何输入文件或已有输出。
- 知识库接入不作为首版验收前提，使用规范化项目信息文件完成测试。

### 8.3 样本要求

- 当前 Word 样本足以开始原型开发。
- 正式声明同时支持 `.xlsx` 和 `.docx` 前，需要补充一个作为填写目标且结构不同的 `.xlsx` 模板。
